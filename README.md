# 读懂 API 与 RAG · 互动学习网站

在线访问：https://yoyo2027.github.io/api-rag-lesson/

给文科同学的入门课，用两个比喻讲两件事：

- **API ≈ 餐厅点单**：程序按约定好的格式，向 AI 点单。页面里可以亲手“寄一封 API 信”，调 temperature 看回信怎样变化，再体验“AI 其实没有记忆”。
- **RAG ≈ 开卷考试**：先从资料里找到相关段落，再让 AI 照着回答。翻书实验里可以切换“按意思 / 按字面”检索，或者关掉资料库，对比闭卷时 AI 怎样编答案。

另有“怎么用”、六道自测题和十张术语卡。

整个网站只有一个文件 `index.html`，下载后双击也能离线打开。页面里的模型回复、资料库和检索打分都是教学示意，不是真实模型的输出；资料库里的“初二英语组资料”是虚构的。
